# REVIEW: почему на карте эмулятора «нет маршрутов» + фикс

**Дата:** 2026-09-17 · **Автор ревизии:** Cline
**Жалоба:** «а почему нет маршрутов прорисованных» (карта `/ui/emulator.html`,
фраза «з Калинки до Універу»: в ответе есть ноги, на карте — только точки ТС).

## 1. Диагноз (воспроизводимый)

Карта рисует линии по `legs[].path` (`web/emulator.js`, `renderPlan`):

```js
const path = Array.isArray(leg.path) ? leg.path : [];
if (path.length > 1) L.polyline(path, { color: leg.color, weight: 6, ... });
```

Оказалось, что `path` содержал **ровно две точки** — посадку и высадку.
Причина не во фронте, а в роутере: Дейкстра «едет» сразу до *любой* следующей
остановки маршрута (`router_layer.py`, `for nxt_pos in range(pos + 1, len(stops))`),
поэтому в восстановленной цепочке состояний у поездки есть только два узла,
а `_transit_leg` строил `path` именно из них → Leaflet рисовал хорду.

Доказательство (диагностика `C:\Temp\diag_stops.py` по `graph.json`):
маршрут `trolley:5:A` содержит 27 остановок, участок «Калинівський ринок →
Стадіон Мальва» — **9 остановок** (0…8, 17.9 мин), а в ответе API было
`"path": [[48.31792,25.959926],[48.31379,25.918589]]` — 2 точки.

Проверка в браузере (puppeteer, до фикса): в `.leaflet-overlay-pane` три
полилинии по 2 вершины (`d="M1003 255L882 273"`), остальное — кружки ТС.

## 2. Фикс

`router_layer.py : _transit_leg()` — путь строится как непрерывный срез
цепочки маршрута между посадкой и высадкой (координаты уже посчитаны в
`route_coords`, порядок совпадает с `route_stops`):

```python
path = [[lat, lon]
        for lat, lon in self.route_coords[route_key][pos_first : pos_last + 1]]
```

`travel_min` не изменился (он и раньше считался как `prefix[pos_last] −
prefix[pos_first]`), `from`/`to`, ожидание и цвет — тоже.

  остановки (до фикса падал бы).

## 4. Что осталось на карте «не как в Google»

`path` — это цепочка **остановок**, а не геометрия дорог: между дальними
остановками линия идёт по прямой. Реальные shape-данные есть только в виде
центров улиц (`Streets/streets.json` — точки, не линии), поэтому настоящая
трассировка по дорогам — отдельная задача (нужны OSM way-геометрии или
match по `data/`), к текущему багу не относится.
